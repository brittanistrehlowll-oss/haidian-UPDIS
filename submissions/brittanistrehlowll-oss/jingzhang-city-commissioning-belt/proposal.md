# 京张·城市联调带
## JING-ZHANG CITY COMMISSIONING BELT
### 从铁路试运行，到AI城市联调｜From Railway Trial Runs to AI City Commissioning

**一句话方案：** 百年前，京张铁路以工程测试和试运行建立可靠的物理连接；百年后，京张AI创新带建立“证据基线—模拟—规则校核—影子运行—有限真实负载—人工监督运行—持续复验/退出”的城市联调制度，让AI不是被展示，而是被验证；不是接管城市，而是获得可审计的有限权限。

> 本方案全部空间落位均为开放共创的概念建议。当前采用主办方仓库维护的 provisional_rough 临时边界，不代表官方红线；官方 polygon、控规、权属、文保和工程资料补齐后，所有面积、比例和地块级判断均须复核。 [source:BOUNDARY-SOURCE] [standard:PROJECT-OFFICIAL-ANNOUNCEMENT]

### 城市没有标准答案：让人类智慧与硅基智慧共同指向更美好的生活

人生没有标准答案，城市更没有标准答案。城市的意义不在于被某个规划师、机构或算法一次性“求解”，而在于让生活在其中的人能够持续感受、选择、创造和修正。过去，城市主要承载并放大人类的经验、制度与工程智慧；未来，来自人工智能系统的感知、计算、推理和协作能力，也会越来越深地参与城市。我们不把两者设成竞争关系，也不把AI设成替居民作出价值判断的“超级大脑”。**人类的智慧和硅基的智慧，都希望让我们的生活更加美好。** 人类提供价值、经验、伦理、情感、责任和最终判断；硅基智慧提供规模化感知、复杂推演、实时协同与持续学习。二者共同服务的对象，不是技术本身，而是人的生活、城市的公共利益与长期韧性。

共同目标不等于无限授权。C0-C6七道联调门因此从技术验收机制进一步成为城市的选择权机制：每一个AI建议先被视为假设，再经过模拟、规则与公共利益校核、影子运行、有限真实负载和人工监督，证据不足就停、风险不可控就退、公众利益不成立就不做。**智慧可以增加，权力边界必须清楚；系统可以越来越聪明，城市必须始终保留人的选择权。** 我们不是让AI替城市决定未来，而是让城市多一种理解自己、改善自己、与居民共同成长的能力。百年京张的下一段历史，不是简单地从钢轨走向算法，而是让人类智慧与硅基智慧第一次在真实城市中，共同服务于更美好的生活。 [standard:PROJECT-AGENT-OPEN-CALL-TASKBOOK] [depth:risk_missing_data]

## 设计依据与资料清单

本方案的正式任务依据来自主办方公告、仓库 `design_brief`、面向智能体任务书、公共资料登记表和临时边界。方案方法同时吸收既有城市规划、市政基础设施、韧性城市、AIDC投产联调、AI赋能控规、城市更新与地下空间研究经验，但不把任何内部客户底图、非公开指标或项目成果上传至公共仓库；只迁移可普适的方法论。 [source:OFFICIAL-ANNOUNCEMENT] [source:AGENT-TASKBOOK] [source:SOURCE-REGISTRY]

核心专业判断有三条：第一，AI城市不能只做“场景清单”，必须设计其物理承载、运行权限和失效状态；第二，监测能力不等于控制权，技术可行不等于制度授权；第三，任何影响交通、能源、市政和公共服务的高风险AI能力都应经过分级验证并保留人工接管、回滚和退出。以上判断在本方案中被空间化为 **Physical City Plane、Institutional AI Plane、Civic AI Overlay 与 C0-C6 七道联调门**。 [standard:PROJECT-AGENT-OPEN-CALL-TASKBOOK] [depth:existing_conditions_diagnosis]

## 三层范围工作框架

**43.6km²统筹研究范围｜CITY SYSTEM。** 按公告北五环—京藏高速—西直门外大街—万泉河路的城市级范围，研究AI科研、产业、人才、算力能源、公共服务与真实场景反馈如何形成闭环。该层使用公告文字面积和任务关系，不以临时 polygon 进行法定面积推定。 [source:OFFICIAL-ANNOUNCEMENT]

**约11.4km²总体设计范围｜CITY COMMISSIONING DISTRICT。** 以京张遗址公园及周边1-2公里城市地区为主要空间载体，形成连续公共脊、东西缝合节点、AI基础设施接口、市政韧性网络与更新项目体系。提交边界由主办方 provisional geometry 复算为约11.41km²，仅用于设计模型。 [data:geometry/site_boundary.geojson#SITE-001] [metric:site_area_sqm]

**三处重点区域约368.4ha｜CITY LABS。** 众智园、北京AI原点社区、大钟寺分别承担“测试验证—真实日常负载—更新规则转化”三种不同任务。三处 polygon 均为临时粗略范围，其边不代表道路或地块红线。 [data:geometry/key_areas.geojson#PROV-KEY-001] [metric:key_area_count]

## 统筹研究范围产业与未来城市研究

### 1. 总体结构：一脊、两平面、三实验区、七道门、一账本

**一脊：京张城市联调公共脊。** 京张遗址公园首先是日常公共空间、慢行网络和百年铁路文化载体，其次才是AI界面。方案不建设连续巨型科技屏幕，而将AI节点小型化并与遮阴、休息、应急、充电、导航、边缘算力和公共解释界面复合。 [standard:MOHURD-URBAN-DESIGN-MEASURES]

**两平面：**
1. **Physical City Plane｜物理城市平面**：水与蓝绿、电力与分布式能源、算力、通信、地下市政、物流与综合交通六类基础网络。
2. **Institutional AI Plane｜AI制度平面**：Evidence、Simulation、Design、Operation、Deliberation五层能力，横贯身份、权限、版本、风险、审批、人工接管、审计、异常、回滚、申诉和退出。

二者通过 **Civic AI Overlay｜城市AI叠加管控层**连接。该叠加层不修改法定用地、容积率和高度，而把传统控规难以表达的AI空间接口、权限上限、测试阶段、运营责任、人工兜底和退出条件结构化为机器可读规则。

**七道门 C0-C6：**
- C0 Evidence Baseline：资料、边界、来源、责任、风险登记；
- C1 Simulation：数字孪生/情景模拟，不连接真实控制权；
- C2 Rule Check：规划、工程、安全、隐私、无障碍、公共利益校核；
- C3 Shadow / Dummy Load：影子运行或假负载，测试冗余、故障和恢复；
- C4 Limited Real Load：限定空间、时间、人群和权限的真实运行；
- C5 Human-supervised Operation：扩大服务但保留人工接管和高风险操作批准；
- C6 Recertification / Rollback / Exit：模型、数据、设施或规则变化即复验，不满足标准则降级、回滚或退出。

**一账本：City Evidence Ledger。** 每个城市AI系统记录 Project ID、空间范围、运营者、责任人、数据/模型来源和版本、风险级别、权限、联调阶段、测试证据、失败事件、人工干预、批准节点、复验触发、回滚和退出。

### 2. 世界级AI创新生态：从“企业集聚”升级为“真实城市验证能力”

京张的稀缺性不应只是聚集更多AI企业，而是提供 **Research → Test → Limited Deployment → Daily Use → Evidence → Rule Update → Re-test** 的真实城市创新闭环。众智园输出测试证据和接口标准，AI原点社区提供真实生活负载，大钟寺把证据转成更新规则和项目机制，中关村科技服务翼提供科研、IP、资本、模型与标准服务，小月河场景赋能翼提供生态、社区、市政与公共服务反馈。 [source:AGENT-TASKBOOK] [metric:ecosystem_case_count]

### 3. 品牌与视觉识别

主名称：**京张·城市联调带**；英文：**JING-ZHANG CITY COMMISSIONING BELT**。核心短句：**PROVE BEFORE SCALE｜验证后再扩展**；治理短句：**HUMAN OVERRIDE BY DESIGN｜人工接管是设计内建能力**。Logo采用“一条连续线+七个门/刻度+双层框架+状态点”的抽象语法，不使用AI脑、芯片、机器人头像或蒸汽机车剪影。 [standard:PROJECT-AGENT-OPEN-CALL-TASKBOOK]

## 总体设计范围城市更新与控规深度城市设计

总体设计不把AI设施叠加到一张普通城市设计上，而把物理基础设施、公共空间和治理规则作为同一设计对象。用地模型使用统一国土空间用地代码，形成科研—公园绿地—商业服务—社区服务的概念功能梯度；它只证明结构化表达和空间接口，不代表审定用地。 [data:geometry/land_use.geojson#LU-001] [standard:MNR-LAND-USE-CLASSIFICATION-GUIDE]

**Civic AI Overlay三类规则：**
- A Mandatory：安全、隐私、公共利益、人工接管、审计、应急不得绕过；
- B Conditional：允许以等效性能满足的条件性要求；
- C Guidance/Experimental：试点、创新和未来迭代。
每条规则采用 `Rule ID + Spatial Scope + Object + Requirement/KPI + Source + Responsible Party + Approval Gate + Version + Evidence + Re-test Trigger + Rollback/Exit`。

**更新策略：** 采用“体检—协商—策划—行动—联调—复验”的渐进更新逻辑。现阶段只给出保留适应、改造开放、新建测试设施、临时可逆使用四类概念动作；缺乏权属、结构、历史价值和法定控制条件时，不指定具体拆除建筑。 [standard:MOHURD-CONTROL-DETAILED-PLANNING] [depth:retain_renovate_demolish]

## 重点区域详细设计

![三处重点区域：测试验证、真实负载、更新规则](assets/figures/key-areas.png)

### A. 众智园｜CITY TESTBED
定位为“AI城市系统进入真实城市前的参考测试设施”。空间模块包括开放测试场、机器人/自主系统测试路网、边缘算力与通信节点、分布式能源/储能接口、模型安全与治理实验室、开发者共享设施。三类关键测试分别为 ICT/算力/终端互操作、机器人与自主物流物理场、市政AI影子运行与故障恢复。测试通过只形成证据，不自动等于获得城市运行许可。 [data:geometry/key_areas.geojson#PROV-KEY-001]

### B. 北京AI原点社区｜LIVING LOAD
定位为世界级AI人才社区和公共AI服务的真实日常负载区。设计优先住房、教育、健康、社区、无障碍、通勤、创新首层和夜间生活；基本公共服务不以注册商业AI账号为前提，关键服务提供人工/电话/实体入口，不以强制数据授权换取基本城市服务。 [data:geometry/key_areas.geojson#PROV-KEY-002] [standard:BARRIER-FREE-ENVIRONMENT-LAW]

### C. 大钟寺｜RENEWAL RULE LAB
定位为AI时代存量更新和详细规划规则实验区。设置规划议事厅、片区—地块协同优化器、机器可读规则校核与更新项目证据账本。空间上采用小尺度渐进更新、存量建筑适应性再利用、临时创新空间、公共服务补短板和站城步行连接改善。AI模拟不替代真实公众参与，也不自动决定容积率、土地权利和拆迁。 [data:geometry/key_areas.geojson#PROV-KEY-003] [depth:three_key_area_detailed_design]

## 交通、轨道、市政与公共服务设施

![交通慢行、蓝绿、市政与AI基础设施复合系统](assets/figures/mobility-bluegreen.png)

**交通：** 京张公共脊优先形成连续步行/自行车系统，并在三处重点区附近设置东西向缝合节点。路缘空间采用时分共享：上下客、配送、自主物流、应急和活动按时间与权限切换。自动驾驶/机器人测试必须有明确地理围栏、测试时段和人工接管规则。

**水与蓝绿：** 海绵、生态、排水和内涝预测统一考虑；AI预测不能替代实体排水能力和应急设施。

**能源与算力：** 采用“区域算力服务+边缘微节点”分层，推动分布式能源、储能、充电和公共建筑柔性负荷协同。关键节点保留应急供能和降级策略。

**通信与地下市政：** 多运营商、多路径和关键节点冗余；设施、管线、地下交通和公共空间统筹维护、更换、事故隔离和应急进入。AI基础设施优先复合现有设施空间，减少重复占地。 [depth:municipal_public_services]

## 蓝绿空间、公共空间与城市风貌

京张遗址公园是“开放创新与公共审计脊”，而不是科技展廊。城市风貌强调真实街道、树荫、低门槛公共空间、铁路遗产连续叙事和小尺度数字界面。建筑体量采用“沿公共脊开放、重点节点形成识别、重点区内部适应产业需求”的原则，不在缺乏控规和文保资料时给出高度数值。 [standard:MOHURD-URBAN-DESIGN-MEASURES] [depth:blue_green_public_space]

4个AI朝圣/公共荣誉节点均为概念工作名：
1. **First Run Yard｜首发试运行场**：铁路试运行历史与AI城市联调起点叠加；
2. **Open Evidence Hall｜开放证据厅**：展示开源方案、规则、数据来源、版本、贡献者和测试证据；
3. **Civic Override Beacon｜公共接管灯塔**：以可理解方式展示“AI有限权限、人类最终责任、系统可退出”；
4. **Commissioning Commons｜联调共享场**：开发者、居民、运维者共同测试和反馈的公共空间。 [metric:ai_landmark_count]
