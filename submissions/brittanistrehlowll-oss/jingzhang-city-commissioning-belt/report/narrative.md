# 京张·城市联调带｜摘要

**城市没有标准答案。人类的智慧和硅基的智慧，都希望让我们的生活更加美好。**

本方案首先对齐官方“三大定位、五大功能、三区两翼”和 agent.1-agent.6 六项任务，再提出自身规划创新：以京张遗址公园公共脊、众智园、AI原点社区和大钟寺构成真实城市设计主体；以 **Civic AI Overlay｜城市AI叠加管控层**回答“AI进入城市后，详细规划需要新增什么规划对象、空间接口与管控规则”。

三处重点区承担不同证明责任：**众智园 CITY TESTBED**验证AI产品进入真实城市前的研发、测试和接口；**AI原点 LIVING LOAD**以AI / 人工 / 离线 / 低或无感知四条等价路径检验真实日常生活；**大钟寺 RENEWAL RULE LAB**以KEEP / ADAPT / TEMPORARY / TRIGGERED和更新单元详规工作台检验存量更新与规则实施。

AI基础设施不恢复“六张网”主叙事，仅保留 **C｜Compute Matching、P｜Compute–Power Coordination、W｜Compute–Water Coordination** 三个AI时代的空间适配专项。通信、地下市政、交通和物流作为普通连接与工程条件。C0-C6七道联调门与City Evidence Ledger保留为运行验证和证据留痕方法，不再承担标题级原创。

实施采用 **NOW / NEXT / CONDITION-BASED** 三类项目包；结构化公共节点保持4处，其中 First Run Yard、Open Evidence Hall、Civic Override Beacon 为3个核心公共荣誉节点，Commissioning Commons为支撑型共享场。所有空间、指标和工程判断均保持provisional/概念建议边界，不虚构法定控规、工程容量或政府实施承诺。
