京张·城市联调带

JING-ZHANG CITY COMMISSIONING BELT

城市没有标准答案。人类的智慧和硅基的智慧，都希望让我们的生活更加美好。

AI时代的城市详规与真实场景创新。 城市设计与真实生活是主体，Civic AI Overlay 是第一规划创新，Compute–Power–Water 是专业支撑，C0–C6 与 City Evidence Ledger 是运行验证和留痕方法。

当前空间模型采用主办方仓库维护的 provisional_rough 临时边界，不代表官方红线；官方 polygon、控规、权属、文保和工程资料补齐后，面积、比例、体量和地块级判断均须复核。

一、总体结构

第一层｜城市设计主体：京张遗址公园公共脊 + 众智园 / AI原点 / 大钟寺三重点区 + 三区两翼。公共空间、生活、产业与渐进更新先成立，AI再叠加其上。

第二层｜Civic AI Overlay：在传统详规之上新增AI时代可规划表达的对象，包括边缘算力接口、能源柔性接口、机器人物流/路缘接口、感知边界、运行权限、人工接管、低/无感知路径、版本证据、复验和退出条件。最小规则单元为 Rule ID → Spatial Scope → Object → Requirement/KPI → Source → Responsible Party → Permission → Gate → Evidence → Version → Re-test → Exit。

第三层｜AI Infrastructure Support：只强化 C｜Compute Matching、P｜Compute–Power Coordination、W｜Compute–Water Coordination。通信、地下市政、交通和物流作为连接、工程与场景适配条件，不恢复“六张网”主叙事。

第四层｜C0–C6 + Evidence Ledger：负责从证据基线、模拟、规则校核、影子运行推进到有限真实负载、人工监督、复验/回滚/退出，不承担方案标题级原创。

二、官方任务主线

三大定位：百年京张文化带 / 都市AI生活体验带 / AI融合创新带。

五大功能：AI全栈自主创新体系 / 世界级AI创新生态 / AI+场景赋能新范式 / 智能化AI活力城市 / AI治理全球话语权。

三区两翼：众智园验证技术，AI原点验证真实生活，大钟寺验证存量更新与规则；中关村科技服务翼连接科研、IP、资本与专业服务，小月河场景赋能翼连接生态、社区、市政和真实场景。

三、三处重点区

区域证明责任设计主张
众智园CITY TESTBEDAI产品进入真实城市前的测试验证：基础设施互操作、机器人/自主物流、市政AI影子运行与故障恢复。
AI原点社区LIVING LOAD以住房、教育、健康、无障碍、通勤和公共服务形成真实生活负载；基础公共服务同时保留 AI / 人工 / 离线 / 低或无感知四条等价路径。
大钟寺RENEWAL RULE LABAI更新单元详规工作台：现状证据 → 多主体协商 → 空间变量 → 公共利益校核 → A/B/C规则 → 项目行动 → 一张图维护 → 复验。

四、AI基础设施适配

C｜算力匹配：区域算力承担大规模训练/高强度计算，片区级服务承担推理、数字孪生、科研共享，边缘节点承担低时延、隐私敏感和高可靠任务；核心城区不默认建设大型AIDC。

P｜算电协调：Protected / Flexible / Migratable 三类计算负荷与电力状态、储能、建筑柔性负荷和任务迁移协同。

W｜算水协调：W0–W3空间适配；只表达冷却方式、水源条件、热排放与审查触发，不虚构MW、MVA、m³/d、管径或工程线位。

五、公共利益与公共节点

基础公共服务强调结果等价：AI入口、人工入口、离线入口、低/无感知路径同时成立。三个核心荣誉节点为 First Run Yard、Open Evidence Hall、Civic Override Beacon；Commissioning Commons 为支撑型共享场。

六、场景、人物与运营

方案包含12张正式AI+场景卡，其中4个产业/规划测试验证场景；8类人物画像；7个全球机制案例。长期运营包括 Commissioning Week、Open Urban AI Plugfest、Civic Audit Open Day 与 Rulebook Release。

七、空间模型与实施

核心设计模型包含 site_boundary、key_areas、land_use、buildings、roads、green_space、public_space、constraints、phasing 等图层，并增加 landmarks 节点层。当前模型指标为约 11.41km²、绿地比例约 17.6%、公共空间比例约 6.7%，均为 provisional 概念设计模型值，不是政府审定指标。

实施采用 NOW / NEXT / CONDITION-BASED：立即可逆行动、下一阶段试点、依赖正式规划/工程/容量/审批的条件性项目分别管理。

八、证据与边界

完整主体方案见 proposal.md / proposal.en.md；机器证据由 compliance_matrix.json、standard_matrix.json、design_depth_matrix.json、metrics.json、sources.json、assumptions.json 与GeoJSON共同承担。缺FAR、高度、产权、文保、市政容量和正式路网等官方条件时保持unknown或明确限制，不使用AI补造确定结论。

本成果为开放共创的城市设计提案，供后续专业团队深化，不构成审批、控规、工程可研或实施承诺。
